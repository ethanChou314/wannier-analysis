A Python module for analyzing and diagnosticating atomic-like wavefunctions (orbitals) extracted from electronic structure calculations. This module supports loading volumetric data (XSF and Cube formats), computing the angular momentum operator ($L_z$) in a numerical basis, and calculating quadrupole moments using a toy radial model. 

This module requires `apply_sym_wan` to be present in your python path for specific file-loading operations.
